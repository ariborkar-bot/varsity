# Varsity: detailed history and feature notes

Moved out of CLAUDE.md on Nov 8 2026 (v336) to keep the always-loaded notes short. Nothing was removed. **Append new per-version notes at the bottom of this file, not in CLAUDE.md.** Search it (grep for a function name or `vNNN`) when you need how a feature works.

## Phone behaviour (Nov 5 mobile audit, owner approved)
- Back button: tabs use `history.pushState`, so the phone's Back goes to the previous tab. Opening a player card or notifications calls `sheetPush()`; Back (popstate) closes the sheet. User closes go through `sheetClose()`.
- Phones (< 760 px): the big banner scrolls away and `#mastMini` (logo, week, settings via `#gear2`) slides in at the top.
- Login server: the real site has `NEEDS_SERVER=true`. If the Supabase library cannot load (jsDelivr, then unpkg as backup), `ME.mode='offline'`: an Offline banner with Try again, `act()` refuses to save, sign-in says it can't connect. Previews set `NEEDS_SERVER=false` and run in demo mode. Hosting supabase.min.js in the repo was approved but not done: package downloads were blocked in that session.
- Pick 'em draws one week of games at a time (`pkWeeksHTML`, Show more adds a week): a basketball season is ~1,400 games.
- Player card / notifications sheet (`.dp`, a flex column with max-height) must scroll as one page: `.dp>*{flex-shrink:0}` stops sections being squeezed (the game log had shrunk to a 39 px inner scroll box). `.dr` z-index 70 sits above the phone tab bar (65); `#toast` 80 (v220).
- Smooth scrolling (v225): background refreshes call `render(true)`, which leaves the page alone when its HTML is unchanged (`LAST_HTML`), and `touch()` waits while a finger is down or the page scrolled in the last 350 ms (`FINGER`, `LASTSCROLL`). `refreshDrawer` skips unchanged cards and keeps the sheet's scroll position. Explicit `render()` calls still always redraw.
- No page jumps on redraw (v226): `render()` folds the page description behind its "i" (`infoIcons()`) right after drawing and restores `scrollY`; the description used to show for a moment and fold away, shifting the page ~60 px (every 10-0 respin jumped up).
- Pull-to-refresh is OFF (owner, v226): the IIFE starts with `return;`, and `html,body{overscroll-behavior-y:contain}` stops the browser's own pull-to-refresh where it can.
- Admin console: only the Exit button leaves (v226). `route()` and the tab-link handler push you back to #admin while `ME.admin` (unless the link has `data-admexit`; #desk is allowed). "Back to app" was removed from the admin side bar.
- 10-0 leaderboard ranks by the team's combined points per game (`teamPPG`, saved as `sim.bppg`; v226). Older saved teams have no `bppg`, so they leave the board until rebuilt. The bar shows Team PPG instead of Spots.
- 10-0 season (v227): every simulated season is `SIM_GAMES`=10 regular-season games: the school's real games (playoff `k:'P'` games and weeks after 11 left out), open weeks filled with the closest-rated schools it did not play (`add:true`). The big pulsing "▶ Simulate season" button (`simGo` → `simFinish(true)`) replaced Finish team: it saves the team and goes straight to choosing a school.
- 10-0 defense is easy to find (v225): the Defense tab pulses with a Tap badge until opened (`UI.simSeenDef`), the field has an Offense/Defense corner tag, and a big "See your defense →" / "← Back to your offense" button sits under the field (`HASDEF`; basketball sets `HASDEF=false`).
- 5 Card Draw: using the last redraw locks the hand automatically (`fcAutoLock`, after the new card's reveal; v233), no confirm box.
- 5 Card Draw: one hand per week for good (v234). `fcDeal` reads `picks/<uid>` from the server before dealing; if a hand exists for the week it is restored instead (and if the read fails, nothing is dealt). The Deal button waits for `S.loaded.picks` ("Loading your hand…"). Preview files (demo mode) don't keep data, so a reload there still starts fresh.
- Minigames tab row fits on phones (v235): under 620 px `.gm-tabs` is a 5-column grid (full names, two lines where needed), so no sideways scrolling to find Ring Chaser / Field Goal / Hoops. Checked at 320, 375 and 393 px.
- Ring Chaser (v249): Your lineup and AI lineup sit side by side (`.rc-two`, also on phones: under 620 px slots are one column, no avatar or stat line, points shown before the school).
- Ring Chaser online wagers and rematch (v252): either player can offer a token wager (5/10/25/50/100) in a party lobby or before the first pick (`d.wg={by,amt,st:'ask'|'ok'|'no'}`); the game waits until it is answered. Winner +amt, loser -amt, tie 0, leaving = loss; settled once per match in each player's own `picks/<uid>.rc.wn` (added in `bank()`). After a match, Rematch / Run it back for N / Rematch with a wager (`d.rm={by,amt}`); the accepter opens a new private match (`rem`, wager carried as `wg.st='ok'`) and writes `d.next={id,code}`; the asker's phone joins with that code (`rcoFollow`). Works with the existing tools/sql/ring_chaser_online.sql rules.
- Over/Under player names open the player card. Join forms start with no position and require one for players.
- Basketball preseason: `PRE()` still counts everyone as one 0.0 game for ranking, but game counts show 0; Simulate says when it opens instead of "Not enough players".

## v250 (Nov 6): Ring Chaser online
- Ring Chaser main card: Play the AI, Find an opponent (`rcoNew(true)`), Create a party (`rcoNew(false)`, 5-letter code from `RCO_ABC`, Send invite shares it) and a code box + Join a party (`rcoJoin`).
- A match is one doc in `rcm` (`bb_rcm` in basketball): host, guest, st wait/live/done/gone, turn `t` (host on even turns), `spin {t,s}`, `sl {uid:{slot:key}}`, `last`, `stuck`. Only the player whose turn it is writes; their phone spins the school and saves it (a reload can't re-roll). 30 s pick clock (`RCO_CLOCK`) then the top player is taken; if the other player is idle 75 s (`RCO_AFK`) you can Take the win. Leaving a live match is a loss. Online record is `picks/<uid>.rc.on {w,l,t}` (`oid` = last counted match); full lineups also count for Best lineup. A match in progress is picked back up after a reload for an hour (localStorage `vs-rco-fb`/`vs-rco-bb`).
